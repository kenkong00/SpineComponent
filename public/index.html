这个系统干了什么

  1. 拆件还原：读取 spine/<角色>/<角色>.json（PhotoshopToSpine 导出的源文件）+ images/ 里那一堆散图，按 JSON 里每个槽位的 x / y / width / height 把部件逐层叠回去 —— 和「把 JSON 拖进 Spine 还原」是同一个结果，只是这里直接在网页上画出来。
  2. 部件分离：还原出来的每个部件都是一个独立的可点选对象。点它 → 右侧上传你自己的 PNG 就能替换，原部件随时 ↺ 还原。
  3. 备用/变体部件：源文件里 slots 没写 attachment 的槽位（侧身、闭眼、换嘴、换眼等）在 Spine 里默认不显示，这里被识别成「备用/变体」，一眼点开就能换上，等于白送一套表情/朝向。
  4. 动作预览：export*/ 里的 json+atlas+png 用官方 Spine 3.8 运行时在网页播放，可切动作、调速、看骨骼线框、截图。
  5. 套装：所有替换/变换都能存成套装（JSON），随时读回来。

坐标是怎么对齐的

源 JSON 里 x,y 是部件中心在 Spine 坐标（Y 向上）中的位置，width,height 是占位框。网页用 Y 轴翻转把中心对齐，所以 left = x - w/2、top = (canvasBottom - (y + h/2))。换上去的图默认会被拉伸到原占位框大小，所以位置天然对得上；也可以用「等比适应 / 等比裁切」。

工作流建议

PS 里做模板化人物（图层分开、命名规范）→ 用 Spine 的 PSD 导入生成 JSON → 丢进 spine/ 目录 → 刷新（右上角 ↻）→ 在这里装配、换部件、存套装。

切割工坊：不装 PS 也能出 Spine 资源

第三个流水线：把一张图变成一套 Spine 资源，全程在网页里完成。

  1. 导入：拖入 PNG / JPG。会自动检测背景类型（透明 / 不透明）并预选切分策略。
  2. 自动切分：
    透明区域按 alpha 通道做连通域标记，一次扫出所有互不相连的区域，再按最小面积过滤碎屑。透明背景的立绘效果最好。
    背景色去除从四边取样背景色 → 容差泛洪去背 → 再做连通域切分。适合白底图、纯色底图。
    网格均分按行列等分，跳过空格子。适合帧序列、精灵表。
  3. 手动修边：魔棒（容差泛洪）、矩形、椭圆、套索生成选区，再「存为新部件 / 加到部件 / 从部件删」；画笔与橡皮直接涂抹在当前部件上补回或擦掉像素。另有羽化、扩展、收缩、平滑、反选。
  4. 整理：自动按位置从上到下重排并命名 part_01…（也可双击改名，支持中文）；可合并、按连通块拆分、删除、隐藏。
  5. 导出：生成 spine/<角色ID>/images/*.png 与 <角色ID>.json（PhotoshopToSpine 格式，可直接被 Spine 的「导入数据」读取），落盘后自动刷新装配台。

坐标怎么来的：原图左上原点、Y 向下；导出时转成 Spine 的「原点在左下、Y 向上」—— x = 左边界 + 宽/2，y = 图高 − (上边界 + 高/2)。装配台用的是相对包围盒，所以拖进 Spine 后部件间的相对位置与网页一致。

必须知道的限制：自动切分靠「像素是否相连」判断，所以互相接触或重叠的部件会被当成一块（比如手贴在身体上）。这时用魔法棒/套索/橡皮手动分开，或改用下面的 AI 智能识别。

AI 智能识别（SAM 3.1 + YOLOv8-pose）

调用你硬盘里 Photon Studio 的本地模型：YOLOv8-pose 先定位人体 17 关键点，再对每个部件给「文本提示 + 几何框提示」，SAM 3.1（1.7GB 权重）语义级抠出头/发/躯干/四肢——左右手、大小臂都分得开，接触重叠的部件不再是问题。

首次点击自动拉起 AI 服务（端口 5311）并加载模型，约 30 秒；模型常驻，之后每次推理只要几秒。
方案人物部件 15 类（含左右）／人物 + 服装 19 类／自定义英文提示词。
配置ai/config.json：Photon Studio 路径、模型路径、设备（cuda/cpu）、端口。
停止 AI点这里 ，或任务管理器结束对应的 python.exe。关掉工坊本身不影响 AI 服务（保持热着，下次秒用）。

切换演示：把「整套皮肤」拆成「逐部件换装」

PSD 用 Spine 的「皮肤」模式导出时，JSON 的 skins 里会并列好几套皮肤（01 / 02 / 03 …）， 每套皮肤各自给每个槽位(slot)一份附件(attachment)。Spine 里只能 setSkin 整套切换， 这里把「皮肤 × 部位」展开成一张矩阵，每个部位都能单独挑一套皮肤里的图 —— 头用 02、身体用 01、手用 03， 任意组合，这就是完整的换装系统。

  1. 自动识别：左边挑模型 → 中间舞台出图，左边矩阵每行是一个部位、每列是一套皮肤，格子就是这个部位在该皮肤下的图。
  2. 三种切法：点单个格子 = 换这一个部位；点上方「整套 01 / 02 / 03」= 整套切换；▶ 整套轮播 自动循环播放，用来做切换演示。
  3. 留空 / 隐藏：右侧详情里可以选 ∅ 留空（这个部位不挂附件），或把整个部位隐藏起来。
  4. 混搭结果回灌 Spine：点「⬇ 导出合并皮肤 JSON」会把当前逐部位的选择合并成一个全新的 skin 写进 JSON —— 原 JSON 里的其他皮肤不动，新皮肤（默认还会同时写成 default）能被 Spine 的「导入数据」直接读，导进编辑器就是混搭后的样子。
  5. 混搭库：保存/读回只存「部位 → 皮肤」这张对照表，不含图片，素材还在就一直有效。
素材怎么放JSON 与图片目录放进 spine/<任意目录>/（例如 spine/[skin]j0000/ 里放 JSON + [skin]images/01|02|03/）。图片放在哪层子目录都能认：附件名 "02/head" 会按「精确路径 → 皮肤名目录 → 同名文件」依次去找。
识别规则skins 是对象且「皮肤数 > 1 或没有 default」= 皮肤型模型，会在「皮肤模型」下拉里列出来；单套 default 的普通源 JSON 仍是装配台的活儿。
坐标每个部位用自己的 x / y / width / height 摆；画布包围盒取所有皮肤所有部位的并集，所以切换皮肤时画面不会跳。
缺部位怎么办某套皮肤没给这个槽位 → 矩阵里那格显示 —、点不动，整套切换时该部位保持不变（Spine 里也一样，缺的槽位会回落到 default 皮肤）。

启动与排错

启动.bat正常入口。重复双击不会报错 —— 检测到服务已经在跑，就直接打开浏览器；没在跑就启动它。关掉黑窗口 = 停止服务。
重启.bat强制重启：先结束旧的实例再起新的。改了 server.js、或旧实例卡死时用。
node launcher.js --status只看状态（运行中 / 未运行），不启动。
node launcher.js --port=5311端口被别的软件占用时换端口。也可以改 启动.bat 里的 set "PORT=5310"。

服务会暴露一个探针接口 /api/ping，启动器靠它判断「端口上的到底是不是本工坊」，因此不会发生误杀其它程序的情况。
