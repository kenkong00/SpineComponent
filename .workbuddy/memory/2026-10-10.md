## 修复「启动.bat 报 EADDRINUSE / 误报没找到 node」
- 问题：双击启动.bat 报 `EADDRINUSE 127.0.0.1:5310`（旧实例还在监听），且 bat 把一切非零退出都说成「没找到 node」，误导排查。
- 修复（长期方案，非 quick fix）：
  - 新增 **launcher.js** 启动器：启动前探测 `GET /api/ping`；是本工坊实例 → 直接开浏览器复用（exit 0）；端口被别的程序占 → 人话诊断（exit 3）；`--restart` 杀旧起新；`--status` 只看状态；`--port=N` 换端口。
  - **killPid 双保险**：taskkill 失败 → powershell `Stop-Process -Id N -Force` 兜底；杀完二次探测端口，进程已退就不算失败。
  - server.js：新增 `/api/ping`（返回 app 签名 `spine-assembly-workshop` + pid + startedAt）；`server.on('error')` 捕获 EADDRINUSE 输出人话后 exit 3（不再甩异常栈）；开浏览器改由 `SPINE_OPEN_URL` 环境变量驱动。
  - **启动.bat / 重启.bat 重写**：找 node 失败、端口占用、复用成功三种情况分开提示（GBK+CRLF 已校验，无 chcp）；只认 ping 签名，不会误杀无关进程。
  - 说明页新增「启动与排错」表格（.abt-tbl，css 变量 --panel2/--line）。
- 实测证据：`cmd //c 启动.bat` 正常起服务（6 角色、导出版 3+1+1）；第二次运行 launcher 输出「已经在运行」exit 0；CDP 验证说明页表格 4 行宽 840px、装配台 j0003 34 部件 34 图层、code 样式生效。
- 坑：本 agent 沙箱里 node `spawnSync('taskkill')` 报 EBUSY（沙箱拦子进程），用户真实双击不受影响；排查时注意区分。

## 新增「切割工坊」页签：网页端抠图→切分→导出 Spine 资源
- 需求：脱离 PS，在网页里完成「导入一张图 → 自动切成部件 → 分配图层命名 → 导出 images/*.png + JSON 给 Spine 用」。
- 参考了两个既有项目（只读调研，未改动）：
  - `I:\TREA work\window操作界面\photopea` → 抄了选区/mask 算法：`Uint8Array` 全图 mask + 魔棒(栈式泛洪+RGBA平方距离容差) + 形态学 + 羽化(可分离盒状模糊) + `maskToAlpha`(destination-in 抠图) + 游程合并 clipPath。
  - `H:\【work】\photon Studio` → 它的自动切分靠 YOLOv8-pose + SAM3（1.75GB 模型），**搬不到网页**；改用「alpha 连通域 / 背景色泛洪去背 / 网格」三条纯 JS 路线。
- 新增文件：`public/js/cutter-mask.js`(算法库,零依赖) → `cutter-engine.js`(数据模型+导出) → `cutter.js`(UI)。
- 坐标系（已实测验证）：原图左上原点 Y 向下 → 导出时转 Spine「原点左下 Y 向上」：`x = bx + bw/2`，`y = H - (by + bh/2)`。部件 PNG 尺寸 == JSON 的 width/height（trim 到内容边界 + padding）。
- 导出 API `POST /api/cutter/export`：写 `spine/<id>/images/*.png` + `<id>.json`（PhotoshopToSpine 格式）。id 正则校验防穿越；**旧 PNG 不预删**（删了会卡 14 秒，见下），改成先覆盖写、响应后 setTimeout 异步清理。
- 实测（CDP 全流程）：合成原图 1765×1059 → 自动切分 16 块/261ms → 魔棒选区 7021px ✅ → 画笔 +1260px / 橡皮 -1426px ✅ → 导出 49ms 生成 + 288ms 上传 = 337ms → 自动刷新装配台，16 部件 16 图层 0 缺图，抽检 8 张 PNG 全部有内容。
- **性能坑（重要）**：`fs.unlinkSync` 在本 agent 环境被 `SAFE_DELETE_BULK_CONFIRM_REQUIRED` 审计钩子拦截，删 17 个 PNG 要 3~15 秒（真正的瓶颈，写 PNG 只要 0.3 秒）。改为不预删后：覆盖导出 14.4s → 0.67s。用户真机可能没这钩子，但改动本身也更稳。
- 已知限制（已写进说明页）：自动切分靠像素连通性，**互相接触/重叠的部件会被当成一块**，需手动修边；语义级「哪块是手」需要 SAM 类模型，纯网页做不到。
